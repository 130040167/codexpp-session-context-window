# 会话上下文调节

点击 Codex 输入区或 Codex++ 用量栏的上下文圆环，查看默认窗口、为当前会话所选模型设置独立窗口，或点重置图标恢复默认。

- 支持直接输入 token 数，也可输入 `400K`、`1.2M`；单位不区分大小写。
- 覆盖只对当前会话中的当前模型生效，不修改供应商设置，也不会带入新会话或分叉。
- 空闲会话立即应用；正在回复时不打断当前轮，下次发送前应用。

需要宿主提供 `codexpp.sessionContext`，且所选本地模型位于 Codex++ 受管目录中。用量栏入口还需要启用「用量状态栏」拓展。此包没有后台、网络或桥接路由权限。

把本仓库作为 Codex++ 拓展包安装即可；旧版宿主缺少接口时不会替换原来的圆环。
